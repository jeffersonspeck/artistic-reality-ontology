# ARO 0.1.0

🇺🇸 [English](#english) · 🇧🇷 [Português](#português)

## English

**SABiOx cycle 1 — baseline.** First version of the Artistic Reality Ontology.

| | |
|---|---|
| Version IRI | `https://w3id.org/aro/ontology/0.1.0` (declared as `owl:priorVersion` of 0.2.0-beta; this file itself predates version IRIs) |
| Files | `aro.ttl`, `aro.owl`, `aro.jsonld`, `aro-shapes.ttl` |
| Size | 26 classes, 29 object properties |

**Contents**
- Modules: artwork and selection, interpretation, representation, situation pattern, evidence and empirical world.
- Reusable, independent `ReferenceSource`, with contextual `EvidenceItem` and `EvidenceAssessment`.
- Correspondence between represented patterns and empirical cases as contestable claims.
- 12 competency questions, 2 SPARQL probes, SHACL constraints and a synthetic example.

**Limits:** labels mostly in English only; no derivation module; no generator (the files were hand-maintained); provisional OntoUML stereotypes.

## Português

**Ciclo SABiOx 1 — linha de base.** Primeira versão da Ontologia de Arte e Realidade.

| | |
|---|---|
| IRI da versão | `https://w3id.org/aro/ontology/0.1.0` (declarado como `owl:priorVersion` da 0.2.0-beta; este arquivo é anterior aos IRIs de versão) |
| Arquivos | `aro.ttl`, `aro.owl`, `aro.jsonld`, `aro-shapes.ttl` |
| Tamanho | 26 classes, 29 propriedades de objeto |

**Conteúdo**
- Módulos: obra e recorte, interpretação, representação, padrão situacional, evidência e mundo empírico.
- `ReferenceSource` reutilizável e independente, com `EvidenceItem` contextual e `EvidenceAssessment`.
- Correspondência entre padrões representados e casos empíricos como alegações contestáveis.
- 12 questões de competência, 2 consultas SPARQL, restrições SHACL e um exemplo sintético.

**Limites:** rótulos em geral só em inglês; sem módulo de derivação; sem gerador (arquivos mantidos à mão); estereótipos OntoUML provisórios.
